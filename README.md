# CodeAlpha Web Scraping Project

## 📌 Project Overview

This project was completed as part of the CodeAlpha Internship.

The objective of this project is to collect publicly available book information from a website using Python web scraping techniques.

## 🎯 Objectives

- Learn the basics of web scraping.
- Understand HTML structure.
- Extract useful information from web pages.
- Use BeautifulSoup to parse HTML.
- Use Pandas to organize the collected data.
- Create a structured dataset in CSV format.

## 🛠️ Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Google Colab
- GitHub

## 🌐 Website Used

Books to Scrape

Website:
https://books.toscrape.com/

This website is designed for practicing web scraping.

## 📊 Data Collected

The following information was collected:

- Book Name
- Price
- Availability

## ⚙️ How It Works

1. Send a request to the website using the Requests library.
2. Receive the webpage HTML.
3. Parse the HTML using BeautifulSoup.
4. Locate the required book information.
5. Extract the book name, price and availability.
6. Store the information in a Pandas DataFrame.
7. Export the dataset as a CSV file.

The project successfully scraped book information and created a structured CSV dataset that can be used for further analysis.
